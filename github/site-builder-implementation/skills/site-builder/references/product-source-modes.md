# Product Source Modes

## upload
Use when the user already has products, files, spreadsheets, images, SKUs, or catalog data.

## ds
Use when the user wants the system to source products by criteria.
Required fields:
- category
- market
- price_range
Optional fields:
- style_constraints
- quantity_target

## none
Use when the user wants a non-product site.
Valid site types:
- brand site
- showcase site
- content site
- lead generation site
- coming soon page
